# Calculadora

## Sobre o Projeto

Este projeto consiste no desenvolvimento de uma calculadora funcional para web, construída utilizando HTML, CSS e JavaScript. A aplicação foi criada para colocar em prática conceitos de manipulação do DOM (Document Object Model) e lógica de programação no front-end.

A interface foi desenhada de forma intuitiva, permitindo que o usuário realize operações matemáticas básicas diretamente na tela, com todo o processamento de cliques e cálculos gerenciados de forma dinâmica pelo arquivo `script.js`.

---

## Funcionalidades

* Realização de operações matemáticas básicas (soma, subtração, multiplicação e divisão).
* Interface gráfica limpa e interativa para o usuário.
* Captura de eventos de clique nos botões da calculadora.
* Atualização em tempo real do display com os valores digitados e os resultados.
* Função de limpar o display (botão de reset).

---

## Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **JavaScript (ES6+)**

---

## Objetivo

O principal objetivo deste projeto é aplicar os conceitos fundamentais de JavaScript no desenvolvimento de aplicações interativas, conectando a estrutura do HTML e a estilização do CSS à lógica de programação para criar uma ferramenta útil e funcional.

---

## Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados conceitos como:

* Manipulação de elementos HTML através do JavaScript utilizando o DOM.
* Escuta e tratamento de eventos de usuário (event listeners).
* Desenvolvimento de lógica de programação para armazenamento de dados temporários e execução de cálculos.
* Criação de layouts organizados com CSS para a estrutura de botões e display.
* Boas práticas na separação de responsabilidades entre estrutura (HTML), visual (CSS) e comportamento (JavaScript).

## Como Executar

1. Clone este repositório:
```bash
git clone [https://github.com/seu-usuario/Calculadora.git](https://github.com/seu-usuario/Calculadora.git)
```

2. Acesse a pasta do projeto:

```bash
cd Calculadora
```

3. Abra o arquivo index.html em seu navegador de preferência para utilizar a calculadora.
